# 本專案的規範

> 這是 Lab 2 的範本。**照抄可以，但建議你自己改幾條**——
> 加入你在 Lab 1 檢核表的**兩層分類**寫下的東西。

## 這是什麼專案

一個課程成績計算工具。讀 `data.json`，算出每個學生的總分與等第，印成報表。

## 怎麼跑

```bash
node report.ts
```

不需要 `npm install`。Node 24 直接執行 `.ts`。

## 規範

- **R1**　禁止使用 `any`。寫出真正的型別。
- **R2**　匯出的函式一律小駝峰、動詞開頭（`loadData` 不是 `Load`）。
- **R3**　組字串一律用 template literal，不要用 `+` 串。
- **R4**　權重、門檻這類數字要抽成有名字的常數，不要散在程式碼裡。
- **R5**　註解要說明**為什麼**這樣做，不要複述程式碼在做什麼。
  （`// sum homework` 這種是複述，沒有價值。）
- **R6**　每個匯出的函式上面要有一行說明。

## 不要做的事

- 不要改 `data.json` 的內容。
- 不要為了通過檢查而刪掉功能——報表的欄位跟數字要跟原本一樣。
