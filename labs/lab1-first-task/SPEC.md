# 規格書：`streak` 指令

> 這是你要 agent 做出來的東西。**先讀完再開始下指令。**

## 功能

顯示**每個習慣**目前的連續達成天數。

## 使用方法

```bash
node src/cli.ts streak
```

**不吃任何參數。** 一次列出所有習慣。

## 輸出

用 `ui.ts` 的 `table()` 印一張表，兩欄：

```
習慣    連續天數
早起    4 天
讀論文  2 天
運動    0 天
```

## 邊界

| 情況 | 應該怎麼算 |
| --- | --- |
| 今天已經做了 | 從今天往前數，數到斷掉為止 |
| **今天還沒做，昨天有做** | **從昨天往前數**（不能算 0） |
| 今天跟昨天都沒做 | 0 天 |
| 完全沒有紀錄 | 0 天 |
| 一個習慣都沒有 | 印一行提示，不要當掉 |

## 不要做的事

- 不要順便算「最長連續天數」——**沒有要求的功能就是多的**
- 不要改動 `habits.json` 的內容（`streak` 是唯讀指令）
- 不要動到其他指令

## 種子資料長怎樣

`./reset.sh` 會產生固定的資料（日期相對於今天）：

| 習慣 | 有紀錄的日子 | 預期連續天數 |
| --- | --- | --- |
| 早起 | 今天、昨天、前天、大前天，再往前斷掉 | **4** |
| 讀論文 | 昨天、前天（**今天沒做**） | **2** |
| 運動 | 沒有 | **0** |

「讀論文」那一列就是用來檢查邊界的：**今天沒做，但不該是 0**。
